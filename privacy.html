Privacy Policy

Last updated: 1 October 2026

Hermes is a private automation application operated by a single individual, for that individual's own use. This policy explains what data the application accesses and how it is handled.

Data accessed

With the account owner's explicit consent, the application accesses data belonging to that owner's own Google account:

  • Gmail messages (read, send, and label management)
  • Google Calendar events
  • Google Drive files, Google Docs documents and Google Sheets spreadsheets
  • Google Contacts (read-only)
  • Google Tasks

How data is used

Data is used solely to carry out tasks the owner requests of the application — for example summarising email, scheduling a calendar event, or locating and editing a document. Data is processed on infrastructure controlled by the owner.

Data sharing

No data is sold, rented, or shared with third parties. No data is used for advertising or for training machine-learning models. No human other than the account owner reads the data.

Google API Services — Limited Use disclosure

Hermes' use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Specifically: data obtained through Google APIs is used only to provide or improve user-facing features that are prominent in the application's own interface; it is not transferred to others except as necessary to provide those features, to comply with applicable law, or as part of a merger or acquisition; it is not used for advertising; and it is not used to train or improve generalised artificial-intelligence or machine-learning models.

Storage and retention

An OAuth refresh token is stored on the owner's own server so the application can act without repeated logins. Mail, calendar and file contents are processed in memory to answer the owner's requests and are not retained in a separate database.

Revoking access

The owner can revoke the application's access at any time at myaccount.google.com/permissions. Revocation takes effect immediately; any stored token stops working.

Changes

Because the application has exactly one user, changes to this policy are made only by that owner.
